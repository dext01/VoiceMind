## Что это

VoiceMind — приложение для голосовых заметок с распознаванием речи и ИИ-анализом текста. Всё происходит **локально, на самом телефоне**:

- 🎙 **Запись и расшифровка** — нажали кнопку, сказали, получили текст. Распознавание речи работает офлайн.
- ✦ **Выделение главного** — отдельный ИИ-компонент вычленяет из расшифровки ключевые мысли, задачи и напоминания.
- ⚡ **Быстрее / Точнее** — выбор в настройках между более лёгкой (быстрее, но грубее) и более точной моделью распознавания — под ваше устройство и задачу.
- 📅 **История по дням** — записи группируются по датам, можно искать, слушать оригинал, экспортировать день в Markdown.
- 🔒 **Приватность по умолчанию** — голос никогда не уходит на сервер. С сервером общается только аккаунт (email, пароль, статус подписки).

## Скачать и установить

1. Зайдите в [наш канал в ТГ]([https://t.me/IVoiceMind) и скачайте последний `VoiceMind.apk`.
2. На телефоне разрешите установку из неизвестных источников (Android спросит сам при открытии файла).
3. Установите APK и запустите приложение.
4. При первом запуске приложение скачает компонент распознавания речи (~466 МБ, один раз, обязательно для работы). ИИ-анализ (~1.5 ГБ) — по желанию, можно скачать позже.
5. Зарегистрируйтесь по email — это даёт **30 дней бесплатного пробного доступа**.

**Требования:** Android 8.0 и новее, ~500 МБ свободного места (плюс ~1.5 ГБ, если захотите ИИ-анализ).

## Подписка

Регистрация открывает 30-дневный бесплатный пробный период. Полноценная платная подписка появится в одном из следующих обновлений — данные и записи никуда переносить не понадобится, всё останется на месте.

## Приватность

- Аудио и расшифровки хранятся только на устройстве и никогда не отправляются на сервер.
- На сервер уходят только данные аккаунта, необходимые для проверки подписки (email, статус, срок действия).
- Разрешение на запись запрашивается явно, и перед каждой записью приложение напоминает получить согласие всех участников разговора.


## Разработка

Нативные зависимости (whisper.cpp, llama.cpp) подключены как исходники в `app/src/main/cpp` и собираются автоматически через CMake при сборке Gradle.
